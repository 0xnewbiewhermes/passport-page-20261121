# The Passport Page of a Country That Isn't There

An invented passport spread for the Republic of Veldara (VLD), drawn entirely by code (`gen_passport.py`, Python + Pillow): data page with portrait and ICAO TD3 machine-readable zone, and a visa/stamps page with a river-barge permit.

Run: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`
